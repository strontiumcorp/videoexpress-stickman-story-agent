# VideoExpress Stickman Story Agent

A team-owned system prompt for creating ten-scene narrated 2D stickman stories in VideoExpress.ai with consistent characters, positive-only prompting, visual image checks, narration, and ordered timeline assembly.

## Use

1. Open [SYSTEM_PROMPT.md](SYSTEM_PROMPT.md).
2. Copy the complete prompt into Claude, Codex, or another browser-capable agent.
3. Enable its visible browser/computer-control capability.
4. Sign in to VideoExpress yourself when requested.
5. Send the four required inputs shown in [examples/example-request.md](examples/example-request.md).

## Contents

- `SYSTEM_PROMPT.md` — the complete production agent prompt
- `examples/example-request.md` — a paste-ready sample request
- `evals/acceptance-checklist.md` — a concise completion checklist

## Security

Never place VideoExpress passwords, GitHub credentials, tokens, or session data in this repository. Users sign in through the normal browser login flow.
